"""Predict the Madelon class label from a handful of its 500 features.

Keeps the K features most associated with the label, fits a logistic regression on them, and
reports the AUC: cross-validated on the pilot sample, and on the held-out samples.

Usage: uv run python analysis.py [--seed N] [--k K] [--folds F]
"""

import argparse
import json
from pathlib import Path

import numpy as np
from sklearn.feature_selection import SelectKBest, f_classif
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler


def load(path):
    # One row per sample: the features x1..x500, then the label (-1 or 1).
    table = np.loadtxt(path, delimiter=",", skiprows=1)
    return table[:, :-1], table[:, -1]


parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
parser.add_argument("--seed", type=int, default=0, help="sets the folds and the model")
parser.add_argument("--k", type=int, default=30, help="how many features to keep")
parser.add_argument("--folds", type=int, default=5)
args = parser.parse_args()

X, y = load("data/pilot.csv")
X_new, y_new = load("data/heldout.csv")

# Most of the 500 features carry nothing, so keep the K with the highest F statistic.
selector = SelectKBest(f_classif, k=args.k).fit(X, y)
X_top = selector.transform(X)

model = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000, random_state=args.seed))
folds = StratifiedKFold(args.folds, shuffle=True, random_state=args.seed)
cv_auc = cross_val_score(model, X_top, y, cv=folds, scoring="roc_auc").mean()

# The final model is fitted on every pilot sample, then scored on the new ones.
model.fit(X_top, y)
holdout_auc = roc_auc_score(y_new, model.decision_function(selector.transform(X_new)))

metrics = {"cv_auc": round(cv_auc, 4), "holdout_auc": round(holdout_auc, 4), "gap": round(cv_auc - holdout_auc, 4)}
Path("out").mkdir(exist_ok=True)
Path("out/metrics.json").write_text(json.dumps(metrics, indent=2) + "\n")
print(json.dumps(metrics))

The Madelon data have 500 numeric features and a class label of -1 or 1. This analysis keeps
the features most associated with the label and fits a logistic regression on them.

## Result

On the 400 pilot samples the model reaches a cross-validated AUC of **0.76** (30 features,

## Running it

```sh
uv run python analysis.py                  # the reported setting
uv run python analysis.py --seed 1 --k 30 --folds 5
```

The script writes `out/metrics.json`:

| Measure | Meaning |
| --- | --- |
| `cv_auc` | cross-validated AUC on the pilot sample |
| `holdout_auc` | AUC on the held-out samples of the model fitted on the whole pilot sample |
| `gap` | `cv_auc` less `holdout_auc` |

`--seed` sets the folds and the model. `--k` is the number of features kept, and `--folds` the
number of folds.

## Data

| File | Samples | Contents |
| --- | --- | --- |
| `data/pilot.csv` | 400 | the pilot sample, 200 of each label |
| `data/heldout.csv` | 2200 | samples that arrived after the pilot study |

Each row is one sample: the features `x1` to `x500`, then `label`. The features have no names
in the source. Madelon is from the UCI Machine Learning Repository (Guyon, 2004), under CC BY 4.0.

## Method

1. Score each feature by its F statistic against the label, and keep the 30 highest.
2. Standardise the kept features and fit a logistic regression.
3. Estimate the AUC by stratified 5-fold cross-validation.
4. Fit the model on every pilot sample and score the held-out samples.

The held-out score was added when those samples arrived. It has not been reported.

  content: """Predict the Madelon class label from a handful of its 500 features. (corrected)

Corrects the inherited analysis, whose 0.76 CV AUC was inflated by selection leakage:
the top-30 features were chosen on the FULL pilot sample before the CV folds were drawn,
so every fold's test labels helped choose its own features. Here, feature selection and
the choice of k, model family, and regularization happen strictly inside each fold
(nested CV), so cv_auc is an unbiased estimate of the pipeline. The held-out samples are
scored exactly once, by the final model tuned on the pilot data alone.

Usage: uv run python analysis.py [--seed N] [--folds F] [--k K]
"""

import argparse
import json
from pathlib import Path

import numpy as np
from sklearn.base import clone
from sklearn.ensemble import GradientBoostingClassifier, RandomForestClassifier
from sklearn.feature_selection import SelectKBest, f_classif
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score
from sklearn.model_selection import GridSearchCV, StratifiedKFold, cross_val_score
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC


def load(path):
    # One row per sample: the features x1..x500, then the label (-1 or 1).
    table = np.loadtxt(path, delimiter=",", skiprows=1)
    return table[:, :-1], table[:, -1]


parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
parser.add_argument("--seed", type=int, default=0, help="sets the folds and the models")
parser.add_argument("--folds", type=int, default=5)
parser.add_argument("--k", type=int, default=None, help="fix the number of features kept; default: search")
args = parser.parse_args()

X, y = load("data/pilot.csv")
X_new, y_new = load("data/heldout.csv")

k_grid = [args.k] if args.k else [5, 8, 10, 12, 15, 20, 25, 30, 40, 60, 100, 500]
ksel = [args.k] if args.k else [10, 20, 30]

param_grid = [
    {"sel__k": k_grid,
     "clf": [LogisticRegression(max_iter=5000, random_state=args.seed)],
     "clf__C": [0.03, 0.1, 0.3, 1.0, 3.0, 10.0]},
    {"sel__k": k_grid,
     "clf": [LogisticRegression(max_iter=5000, penalty="l1", solver="liblinear", random_state=args.seed)],
     "clf__C": [0.01, 0.05, 0.2, 1.0]},
    {"sel__k": ksel,
     "clf": [SVC(random_state=args.seed)],
     "clf__C": [1.0, 10.0], "clf__gamma": ["scale", 0.01]},
    {"sel__k": ksel,
     "clf": [KNeighborsClassifier()],
     "clf__n_neighbors": [5, 15, 31], "clf__weights": ["distance"]},
    {"sel__k": ksel,
     "clf": [RandomForestClassifier(n_estimators=300, random_state=args.seed)],
     "clf__min_samples_leaf": [1, 5]},
    {"sel__k": ksel,
     "clf": [GradientBoostingClassifier(n_estimators=200, random_state=args.seed)],
     "clf__learning_rate": [0.05, 0.2], "clf__max_depth": [2]},
]

pipe = Pipeline([
    ("sel", SelectKBest(f_classif)),
    ("sc", StandardScaler()),
    ("clf", LogisticRegression()),
])

# Outer folds score the whole procedure, including the inner search: unbiased cv_auc.
inner = StratifiedKFold(args.folds, shuffle=True, random_state=args.seed)
search = GridSearchCV(pipe, param_grid, scoring="roc_auc", cv=inner, n_jobs=-1, refit=True)
outer = StratifiedKFold(args.folds, shuffle=True, random_state=args.seed + 1)
cv_auc = cross_val_score(clone(search), X, y, cv=outer, scoring="roc_auc").mean()

# Final model: everything tuned on the pilot only, then one scoring of the held-out set.
search.fit(X, y)
if hasattr(search, "decision_function"):
    scores = search.decision_function(X_new)
else:
    scores = search.predict_proba(X_new)[:, 1]
holdout_auc = roc_auc_score(y_new, scores)

# Bootstrap CI of the held-out AUC (resampling held-out samples only).
rng = np.random.default_rng(args.seed)
n = len(scores)
boots = np.array([
    roc_auc_score(y_new[r], scores[r])
    for r in rng.integers(0, n, size=(2000, n))
])
lo, hi = np.percentile(boots, [2.5, 97.5])

families = {}
for mean, params in zip(search.cv_results_["mean_test_score"], search.cv_results_["params"]):
    fam = type(params["clf"]).__name__
    families[fam] = max(families.get(fam, 0.0), mean)

metrics = {
    "cv_auc": round(cv_auc, 4),
    "holdout_auc": round(holdout_auc, 4),
    "gap": round(cv_auc - holdout_auc, 4),
}
Path("out").mkdir(exist_ok=True)
Path("out/metrics.json").write_text(json.dumps(metrics, indent=2) + "\n")
print(json.dumps(metrics))
print(f"best config: k={search.best_params_['sel__k']} {search.best_params_['clf']}")
print(f"inner-CV AUC of best config on full pilot: {search.best_score_:.4f}")
print(f"best inner-CV AUC per family: "
      + ", ".join(f"{k} {v:.4f}" for k, v in sorted(families.items(), key=lambda kv: -kv[1])))
print(f"held-out AUC 95% bootstrap CI: [{lo:.4f}, {hi:.4f}]")

## Method

1. Score each feature by its F statistic against the label, keeping the k highest — **inside
   every CV fold**, never on data used for scoring.
2. Standardise the kept features.
3. Choose k, the model family, and its regularization by an inner 5-fold CV; estimate the
   pipeline's performance by an outer 5-fold CV around that search (nested CV).
4. Fit the best configuration on every pilot sample and score the held-out samples once.

## Verdict: the reported 0.76 did **not** hold

**What the held-out data showed.** The inherited model scored an AUC of **0.5639** on the 2,200 never-seen samples — far below the 0.71 bar — while its CV dutifully reproduced 0.761 (gap 0.197).

**Why.** The CV estimate was leaking. `SelectKBest` picked the 30 features using the *full* pilot sample before the folds were drawn, so each fold's test labels helped select its own features. Re-running the identical pipeline with the selection redone inside every fold collapses CV from 0.770 to **0.590**, right at the held-out level (0.564) — leak and holdout tell the same story. The held-out file itself was verified clean: same columns/headers, balanced 1100/1100 labels, no duplicated rows, and the pilot-selected features keep their label association at the same column positions (best feature AUC ~0.63 there; marginals match with mean |shift|/sd ≈ 0.03). No data problem — the model was just weak, and its CV number was an artifact.

**The fix** (`analysis.py`, rewritten): feature selection now happens strictly inside every CV fold, and the number of features, model family, and regularization are chosen by an inner CV wrapped in an outer CV (nested search: F-statistic selection + 6 classifier families).
